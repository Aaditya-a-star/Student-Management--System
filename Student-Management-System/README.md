# Student Management System

A small beginner-friendly web project built with HTML, CSS, and JavaScript. It is intended for practicing Git and GitHub.

## Features

- Add a student using their name and roll number
- Display the current student list
- Prevent duplicate roll numbers
- Delete a student
- Responsive layout for mobile and desktop

## Run locally

1. Download or clone this folder.
2. Open `index.html` in a web browser, or open the folder in VS Code and use a local server extension.

No build tools or dependencies are required.

## GitHub practice

Try uploading this project to a new, empty GitHub repository using:

```bash
git init
git status
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace the repository URL with the HTTPS URL of your own GitHub repository.

## Note

The student list is stored in browser memory only. Refreshing the page clears the list; this practice project does not use a database.
